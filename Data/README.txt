In this folder:

SnowMap.jpg		A georeferenced image of John Snow's map
CholeraDeaths.*		Shapefile for John Snow cholera deaths used in the tutorial
WaterPump.*		Shapefile for water pumps in Soho district
StudyArea.*		Shapefile for a suggested study area boundary


These data were orginally created by Robin Wilson see: http://blog.rtwilson.com/john-snows-famous-cholera-analysis-data-in-modern-gis-formats/
Points for each location of one or more deaths. Attribute value gives number of deaths at that location Points for each location of a pump

Created and compiled by Robin Wilson (robin@rtwilson.com, www.rtwilson.com/academic) - Jan 2011.

Changes by John Lowry (14 Jan 2019)
-Converted into geodatabase format and ArcGIS Pro project
-Water pump names added
-Projected data from OSGB_1936_BNG to 1984_UTM_60S  (necessary to do spatial statitics, OSGB CS did not work)
